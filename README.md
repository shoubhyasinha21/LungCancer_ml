# Lung Cancer Prediction using Machine Learning

## 📌 Project Overview
This project predicts the likelihood of lung cancer using machine learning techniques.  
It uses patient medical data and a trained ML model to determine whether a person may have lung cancer.

The model is trained using a dataset containing various medical and lifestyle features.

---

## 🚀 Features
- Data preprocessing and feature selection
- Machine Learning model training
- Lung cancer prediction based on user inputs
- Streamlit web application for user interaction
- Model deployment ready

---

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Pickle
